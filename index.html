¡Bienvenidos a B-Kids!

Sistema integrado en la nube para control de asistencia y monitoreo en tiempo real de Iglesia Bethania.

Registro de Niños

Asigna un código único (1-1000) e ingresa fotos y datos de contacto.

Check-In (Entrada)

Busca rápidamente al niño para ingresarlo e imprimir el ticket del papá.

Check-Out (Salida)

Valida el código entregado por el padre y autoriza la salida segura.

Pantalla TV (Estados)

Modo de monitoreo gigante en tiempo real diseñado para televisores.

Reportes y Excel

Consulta el historial diario de asistencias y exporta datos fácilmente.
